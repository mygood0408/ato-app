# 세션 S11 인수인계서 — 확인필요 도면 항목 검증·확정 (나머지 13개 역 → SIN1·SIN2 잔여) (2026-09-30)

선행: S8 완료(커밋됨). 사용자 지시: **13개 역(697건)을 먼저, SIN1·SIN2 잔여 71건은 그 뒤(이미지 확인이 필요한 유형이 더 나올 수 있어 후순위).**

## 입력
- `claude/s8_남은목록.json` — 확정 못 한/미처리 항목 768건(보드·역/시스템·문서·쪽·사유). SIN 외 13개 역 697건, SIN 71건.
- `claude/s8_score.py`(쪽 텍스트·핵심어 함수), `claude/s8_confirm.py`(SIN1·SIN2 판정·JSON/HTML 동기화). 재실행 가능.
- 현재 규칙(SIN1·SIN2에서 검증됨): ① FTGS TX/RX1/RX2 궤도회로는 제목 블록+이미지 확인 ② 핵심어(보드 id 접미사·이름 첫 단어)가 항목의 모든 쪽에 2회 이상 ③ 보드 계통↔도면 종류 일치(SICAS_·ECDSTT_ ↔ SICAS_HW_Design, LZB_·ATOLOOP_ ↔ ATP_HW_Design) ④ 범용 핵심어(FAN·OLM·PS·IFC·TWC·UPS·PSD·FTGS…)는 스크립트 확정 금지.

## 작업
1. **`s8_confirm.py` 규칙을 13개 역(EUL GCD GYO HON SCD SNU1 SNU2 SOL SON1 SON2 SPO1 SPO2 YAN)으로 확장.** 역 목록·도면 문서명(`SICAS_HW_Design_<역>`, `ATP_HW_Design_<SNU|SON|SPO>` 등 시스템 공유 문서)을 자동으로 뽑고, 역 문서가 없거나 쪽 수가 특이한 경우(예: SCD SICAS 쪽 수 적음, SIN2·SNU2·SON2는 EC/DSTT·SV2602 쪽 없음)는 사유를 남기고 넘긴다.
2. 확정(`confirmed:true`, note 삭제)·오매칭(재매칭/삭제, S8 지시 2번 규칙)·보류를 스크립트로 분류. 출력은 개수·쪽번호·한 줄 요약만. JSON·HTML 동기화(`s7b_rematch.py` 방식). 보류 사유별로 `s8_남은목록.json` 갱신(파일명은 `s11_남은목록.json`으로 새로 저장 가능).
3. 13개 역에서 **스크립트로 못 정하는 유형**을 사유별로 집계 → 이미지 확인 방식(쪽별 필요한 영역만 크롭 1장) 설계. **이 단계에서 SIN1·SIN2 잔여 71건도 같은 방식으로 함께 처리**(사용자 결정: 후순위).
4. 도면을 봐도 못 정한 항목은 목록으로 사용자에게 보고(보드, 역/시스템, 문서, 쪽번호, 이유). 임의 확정·삭제 금지.
