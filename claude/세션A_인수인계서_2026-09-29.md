# 세션 A 인수인계서 — 쪽수 라벨 + 목차 걸러내기 (2026-09-29)

## 목표 (이 세션은 이것만)
1. 고장사례 상세의 "📄 원본 매뉴얼 확인 페이지" 각 줄에 **절 이름**을 붙인다.
   - 현재: `SICAS 유지보수 매뉴얼 p.106 (§4.7.1 · 확정)`
   - 목표: `4.7.1 터미널 스트립 레벨 G(수직) → p.106 (확정)` / `6.1 수리지침표 → p.65 / p.129 (확인필요)`
   - 절 제목은 각 사례의 `manualRefs`("4.7.1 터미널 스트립 레벨 G(수직)")에서 절 번호로 가져온다. `source.section`(예: 6.1)은 사례가 실린 위치라서 제목이 manualRefs에 없을 수 있음 → 없으면 절 번호만 표시.
2. "확인필요(후보다수)" 항목을 **목차 걸러내기 규칙**으로 줄인다.
   - 목차 페이지: 한 페이지에 절 번호 다수(예: 15개 이상), 줄 끝이 점선+쪽수, 문서 앞쪽, 본문 문장 적음
   - 본문 페이지: 절 번호+제목이 줄 맨 앞, 뒤에 설명 문장
   - **순서 제약(가장 강함):** 절 번호가 커지면 쪽수도 커진다. 6.1은 5.x 쪽수와 6.2 쪽수 사이.
   - 머리글/바닥글 반복 제목은 제외
   - 끝나면 확정/확인필요 개수 전후를 보고할 것
