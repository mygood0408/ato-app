## A. 쌍동 표시회로 재작업 (계통도 205·206 현장 페이지 기준)
확정된 사실(2026-10-03, `ref/` 이미지 + `sim2.py` 로 검증):
1. **205 = 우(RIGHT)정위, 206 = 좌(LEFT)정위.** 206 정위 ≡ 205 반위, 206 반위 ≡ 205 정위(두 쪽 이미지 픽셀 차이 ≈1%, 정위끼리는 ≈5%). 호기 역할: 205A ≡ 206B(위 단), 205B ≡ 206A(밑 단).
2. **전기적 대응:** 우정위(205)의 "정위" 페이지 점선 = 전기적 **R접점** 상태(표시 (+)→단자 6, (−)→단자 3), "반위" 페이지 = **N접점**((+)→5, (−)→4). 좌정위(206)는 반대. 회로는 같고 라벨·극성 표기만 바뀜. 팝업에 **좌정위/우정위 토글**(쌍동)을 두고 정위/반위 라벨·극성·호기 순서를 같이 바꿀 것.
3. **예비단자:** 기구함 표시 입력 38(+)초록/37(−)회색 선은 **밑 단 호기(205는 B, 206은 A = "메인")의 맨 왼쪽 하늘색 캡 아래 예비단자 2칸**에 도착하고, 그 단자에서 다시 선이 나와 **위 단 호기의 N4(+)·10(−)** 로 올라간다. 호기 순서: 기구함 → 밑 단 예비단자 → 위 단 입력 → 위 단 접점 → 위 단 출력 → 밑 단 입력(N4·10) → 밑 단 접점 → 밑 단 출력 → 기구함(40(+)/39(−), 정위/반위에 따라 극성 바뀜). 출력 (+)선(초록)은 다음 호기 N4, (−)선(회색)은 10 으로 들어감.
4. 쌍동 점퍼: A (R3-N4)(8-10)(3-1)(2-4), B (5-3)(1-2)(4-6) (설치상세도 점퍼표, 계통도 오렌지 U 와 일치).
5. 제어전원: 정방향 극성=N, 역방향=R (205 정위 페이지가 역방향). 모터: 기구함 47/49(BX)·48/50(CX) 가 A·B 로 병렬.
- **현재 구현의 문제:** `wiring_flow.double_flows()` 의 표시 흐름은 이전 해석(방향 반대, 예비단자 없음, A 가 항상 위)이며 `wiring_states.LINKS` 연결선도 이전 해석. 팝업 안내문에 "재작업 예정" 문구를 넣어 둠 → 이 세션에서 전면 교체.
- 할 일: (a) 계통도 205 정위·반위 페이지로 A→B 연결선(출력 단자 → 다음 호기 N4/10)을 다시 읽어 `LINKS` 교체, (b) 예비단자 구간 추가(기구함→밑 단 예비단자→위 단 입력), (c) 좌/우정위 두 버전(호기 위·아래 순서 포함), (d) `sim2.py` 로 두 호기 직렬 연결(+ 점선 경로 4가지)을 검증한 뒤 흐름선 생성, (e) 안내문 갱신.
