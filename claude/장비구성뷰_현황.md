## 기능 메모 (구현 완료, 위치만)
- 사진/동영상: 상단 "폴더 열기"(webkitdirectory, 모바일은 갤러리 다중 선택), 마커, 동영상 ≤10초, 카메라 아이콘 퀵프리뷰(마커 읽기전용 표시), "이 장비에 사진 지정"(sectionId 단위, localStorage). 사진은 브라우저 탭 메모리에만 있어 기기 간 동기화 안 됨.
- 고장상황 탭: 도메인 필터, ★ 즐겨찾기(localStorage), 아코디언 단일 펼침(`state.faultOpenId`).
- 시스템 지도: 핀치줌·팬, 노드 클릭 → 랙 구성 연결, 초기 배율은 JS `mapSizeWrap()`.
- 과거 버그 교훈: ① 전역 `img,svg{max-width:100%}`가 지도 SVG를 찌그러뜨림 → `.map-svg{max-width:none}`. ② flex 자식은 `min-width:0`·긴 라벨은 `overflow-wrap:break-word`(모바일 가로 넘침). ③ 보드 이미지 id 중복 키가 기존 이미지를 덮어쓴 사고(FTGS_TUNING_UNIT) → 새 이미지 등록 전 키 중복 확인. ④ 조립형 보드의 중첩 `<svg>`는 잘림 주의.
