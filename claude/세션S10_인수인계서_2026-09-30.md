3. 신호기·기구함 탭: 측정지점·보드 데이터가 아직 없음. 사진을 보고 (a) 그릴 부품 목록, (b) 측정지점 후보를 정리해 사용자에게 확인받은 뒤 진행. 새 측정지점 값·정상범위는 근거 없이 만들지 않는다(`확인필요`).

## 추천 작업 방식 (디테일한 디자인 조정을 쉽게 + 토큰 절약)
문제: SVG가 3.4MB HTML 안의 한 줄 문자열이라, 디자인을 한 번 고칠 때마다 큰 파일을 열어야 하고 고칠 위치 찾기도 어렵다. 아래 4가지를 적용하면 조정이 빠르고 토큰이 거의 들지 않는다.

**① SVG를 별도 파일로 분리 + 한 줄 동기화**
- 그림은 `board_svg/<보드ID>.svg` (예: `board_svg/FIELD_SWITCH_MACHINE.svg`)로 저장하고 편집한다. HTML 안 `BOARD_SVG` 는 스크립트가 채운다.
- `claude/sync_board_svg.py` (S10에서 작성, 30줄 정도): `board_svg/*.svg` → HTML의 `BOARD_SVG` 항목만 교체(정규식 `^  "ID": "<svg.*?</svg>",?\n`) . 실행: `python claude/sync_board_svg.py`. SVG를 고친 뒤 이 한 줄만 실행하면 화면에 반영된다.
- 효과: 고칠 때 SVG 파일(수 KB)만 읽고 쓰면 되고 HTML은 열지 않는다.

**② SVG 안 구조 규칙 (조정할 곳을 이름으로 찾기)**
- 색·굵기는 SVG 맨 위 `<style>` 안 클래스/변수 한 곳에서 관리: 예 `.body{fill:#8a8f94}` `.accent{fill:#c0392b}` `.label{font-size:11px}`. 색을 바꾸려면 이 줄만 고친다.
- 부품마다 의미 있는 `id` 를 붙인다: `<g id="cover">`, `<g id="terminal-A">`, `<rect id="lamp-1">`. 사용자가 "cover 를 10% 넓게", "terminal-A 를 오른쪽으로 20px" 처럼 **이름으로** 요청할 수 있고, 수정도 해당 요소 몇 줄만 바꾸면 된다.
- 측정지점 위치는 SVG 안 요소에 `data-mp="MP_FIELD_SW_CONTROL"` 을 붙이는 **핫스팟**으로 만든다(별도 좌표 파일 불필요). 앱은 SVG 안 `[data-mp]` 클릭 하나만 처리하면 되고(위임 핸들러), 그림을 고치면 핫스팟도 같이 움직인다. 클릭 시 기존 `renderMpDetail(mpId)` 를 열면 된다.

**③ 디자인 조정 도구 `claude/svg_tuner.html` (한 번만 만들고 계속 사용, 사용자가 직접 조정 가능)**
- 만드는 것: 단일 HTML 파일(라이브러리 없음). SVG 파일을 불러와 화면에 크게 보여주고, 요소를 눌러 값을 바꾸는 도구.
- 사용법(사용자용):
  1. 브라우저에서 `http://localhost:8765/claude/svg_tuner.html` 을 연다(미리보기 서버 사용).
  2. 「SVG 열기」로 `board_svg/…svg` 선택 → 그림이 나오고 오른쪽에 `id` 있는 요소 목록이 나온다.
  3. 요소를 그림에서 클릭하거나 목록에서 고르면, x·y·너비·높이·채움색·글자 크기 입력칸이 나온다. 숫자·색을 바꾸면 **즉시 그림에 반영**되고, 방향키로 1px씩 이동, Shift+방향키로 10px 이동.
  4. 「원본 사진 겹쳐보기」: 사진 파일을 불러와 투명도 슬라이더로 그림 뒤에 깔아 **사진과 나란히/겹쳐서 대조**한다(같은 모양으로 맞추는 핵심 기능).
  5. 「저장」: 수정된 SVG를 다운로드(같은 이름으로 `board_svg/` 에 덮어쓰기) 또는 「변경 목록 복사」로 `#cover x:+12 w:+30` 같은 짧은 변경 목록을 복사해 채팅에 붙여넣기 → Claude 가 SVG 파일에 반영.
  6. 그 뒤 `python claude/sync_board_svg.py` → 앱 화면 확인.
- 효과: 위치·크기·색의 미세 조정은 사용자가 도구에서 직접 하고, Claude 는 결과만 반영하므로 "조금만 더 오른쪽" 같은 왕복 대화와 스크린샷이 크게 줄어든다.

**④ 사진 대조는 「합성 이미지 1장」으로**
- 만든 SVG를 사진과 같은 크기 PNG로 렌더(`pymupdf` 또는 브라우저 캡처)한 뒤, 사진 크롭(왼쪽)+SVG(오른쪽)를 한 장에 붙여 **1장만** 확인한다. 반복 수정 때마다 여러 장을 보지 않는다.

- 서브에이전트는 만들지 않는다. 이 문서에 없는 일은 하지 않는다.
