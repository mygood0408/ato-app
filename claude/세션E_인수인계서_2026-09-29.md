# 세션 E 인수인계서 — SIN1↔SIN2 차이 확정 (2026-09-29)

## 목표 (이것만)
- 세션 D 비교 결과(`claude/compare_sin1_sin2.py`)를 바탕으로 보드별 SIN2 차이를 확정해 `relatedDrawings.SIN2[].note` 에 반영. 고유 내용(단자·전압·랙 배치) 본격 입력은 범위 밖.

## 알려진 사실
- SIN1/SIN2 = 같은 역(신도림)의 다른 시스템/구간(사용자 확인). 구조 `relatedDrawings:{SIN1:[..],SIN2:[..]}`.
- 갱신 스크립트 `claude/sync_related_drawings.py`(멱등, JSON+HTML 동시). SIN2 '자동매칭' 항목만 재생성, note가 '자동매칭'으로 시작하지 않는 수동 항목은 보존 → **확정 결과는 note를 다른 문구로 바꿔서 넣어야 sync 때 덮어쓰이지 않음.**
- 비교 결과 요약(세션 D 인수인계서 "작업순서 3 결과" 참조): C등급(차이 큼/SIN2 없음) = ECDSTT_DESIMO/DEWEMO/STEKOP/PLATTER, ECDSTT_PS, ATOLOOP_CB, TWC_AMP_MODULE·TWC_LOOP_COIL·UPS_RECTIFIER_UNIT·UPS_OUTPUT_DISTRIBUTION(ATP). B등급 = IFC_COMPUTER, IFC_EMS_RELAY, PSD_TERMINAL_MAP, TWC_*(SICAS), UPS_*(SICAS), OLM 등. A등급(≥0.85)은 손대지 않음.
- 화면은 note 문구를 그대로 보여주므로 UI 수정 불필요. 역/시스템 선택 UI는 두 번째 역 데이터 작업 때 별도 설계(세션 D 결론).

## 작업 순서 (C → B, A는 스킵)
1. **C등급: SIN2에 장비가 있는지 먼저 확인.** SIN2 SICAS 도면(150쪽)의 목차·도면 제목 쪽만 훑음(전체 읽기 금지). 없으면 SIN2 항목 note = "SIN2 해당 없음 · 도면 확인" 로 확정, 있으면 B 방식. 장비 계열별(EC/DSTT → ATOLOOP → TWC/UPS) 한 번에 처리.
2. **B등급: 토큰 차집합 표 스크립트 작성** (`claude/`에 저장, 읽기 전용). 보드별로 SIN1에만/SIN2에만 있는 토큰 각 20~30개만 뽑아 표로 출력. 모델은 표만 읽고 "실제 차이 / 단순 번호 차이" 판정. 의심되는 1~2쪽만 이미지 crop으로 확인.
3. 확정된 것만 JSON 수정 → sync 스크립트(HTML 동기화) → 즉시 커밋. 몰아서 하지 않음.
4. 진짜 차이가 확인된 보드 목록만 "고유 내용 후보"로 남기고 입력은 다음 세션.

## 토큰 절약 규칙
- 페이지 원문 덤프 금지: 텍스트는 스크립트 안에서만 읽고 모델에는 수치·diff 표만.
- 결과는 파일(CSV 등)로 저장해 다음 세션이 재계산하지 않게 함.
- 도면 이미지는 최후 수단, 필요한 영역만 crop. 전체 쪽 통째 보기 금지.
- 등급이 아니라 장비 계열 단위로 세션을 나눔(같은 쪽 재읽기 방지).

## 세션 E 결과
- 방식: 장비 존재 여부는 SIN2 KB 키워드 검색(쪽수 카운트+맥락 몇 줄), B등급은 `claude/diff_sin1_sin2_tokens.py`(도면번호 sin1/sin2 접두·문서ID 정규화 후 차집합, 결과 `claude/sin_diff_b.csv`). 표 기준 **추정**이며 도면 이미지 대조는 안 함 → note에 모두 '확인필요/도면 확인' 유지, '직접|완료|확정' 단어 미사용.
- **SIN2 해당 없음(7보드)**: ECDSTT_DESIMO/DEWEMO/STEKOP/PLATTER(SIN2엔 범례 9쪽·Platter 1단어 언급뿐, EC/DSTT 캐비닛 도면 없음), TWC_AMP_MODULE/TWC_LOOP_COIL(SICAS 범례 9쪽뿐, ATP SIN2에 TWC 없음).
- **구성 다름(도면 확인)**: ATOLOOP_CB(ATP/SICAS), UPS_RECTIFIER_UNIT/UPS_OUTPUT_DISTRIBUTION(SICAS SIN2엔 UPS 있음(P51 캐비닛)·ATP SIN2엔 없음), UPS_ATS_AVR_UNIT·IFC_EMS_RELAY·SICAS_OLM·ECDSTT_OLM·IFC_COMPUTER·LZB_FTGS_DISTRIBUTOR (모두 SICAS).
- **단자번호만 다름(확인필요)**: ATP의 IFC_EMS_RELAY·LZB_FTGS_DISTRIBUTOR·UPS_ATS_AVR_UNIT·PSD_TERMINAL_MAP_SIN051·LZB_FAN·ATOLOOP_FAN, SICAS의 SICAS_MELDE2·LZB_MELDE2·LZB_FAN·ATOLOOP_FAN·SICAS_BUMA·LZB_BUMA. (차집합 대부분이 도면번호·단자 참조 토큰)
- **SIN2 텍스트가 SIN1의 일부뿐**: ATP의 SICAS_BUMA·LZB_BUMA·IFC_COMPUTER·ATOLOOP_REMEMO (SIN2 쪽 고유 토큰 0~1개).
- 미처리: ECDSTT_PS(SV 2602)는 SIN2 항목 자체가 없고 SIN2 KB에도 SV 2602 없음 → 화면 표기 변경 없음. A등급(≥0.85)은 스킵.
- **고유 내용 후보(다음 세션 입력 대상)**: 구성 다름 보드 중 SIN2에 실제 존재하는 것 — ATOLOOP_CB, UPS_ATS_AVR_UNIT, IFC_EMS_RELAY, SICAS_OLM/ECDSTT_OLM, IFC_COMPUTER, LZB_FTGS_DISTRIBUTOR, UPS_RECTIFIER/OUTPUT.
- 남은 문제: 정규화해도 같은 페이지 내 표기 차이는 이미지 대조 없이 확정 불가. sync 스크립트는 note가 '자동매칭'으로 시작하지 않는 SIN2 항목을 보존함(확인 완료).

### 도면 대조 추가 (2번+3번: 구성 다름 보드 중 특정 쪽이 있는 계열만)
- 쪽 짝은 키워드 매칭 쪽이 아니라 제목으로 골라야 함(UPS의 SIN1 178쪽은 MELDE2 회로도였음). 이미지는 계열당 1~2장, 두 쪽 합성.
- OLM(SICAS_OLM·ECDSTT_OLM): SIN1 183쪽 S51 OLM 6개(ATP L51·HON·YAN·SIN2 S52·SNU1·S&D·IF-C) vs SIN2 104쪽 S52 OLM 4개(SIN2 ATP L52·SIN1 S51 BUMA0/2·S&D) → 구성 다름 대조함.
- UPS 3보드(RECTIFIER·OUTPUT·ATS_AVR): SIN1 106쪽 T52(EC/DSTT 캐비닛) vs SIN2 107쪽 S52(60V/24V/230V 단자·UPS P51) → 대조함.
- ATOLOOP_CB ATP: 텍스트 제목만 비교, SIN1 신도림 vs SIN2 신대방·구로공단(이미지 미확인).
- 미대조(키워드가 넓어 쪽 짝이 불명확): IFC_EMS_RELAY, LZB_FTGS_DISTRIBUTOR, IFC_COMPUTER, ATOLOOP_CB SICAS → 문구 그대로 유지.
