# 역 확장 설계 결정 (S3, 2026-09-29)

근거: `claude/역_인벤토리.md`. 아래 5건은 사용자가 확인한 것(2026-09-29). 확정 표기는 이 문서 안에서만.

## 결정
1. **역 키/매핑**: `relatedDrawings` 키 = KB 문서 접미사(SIN1, SIN2, SNU1 …) 유지. `stations.json` 1개 추가 — 역 코드 → 시스템 접미사 목록, 주 캐비닛(S51 등), SICAS/ATP 문서 파일명, 쪽수. `역_인벤토리.md`에서 스크립트로 생성.
2. **데이터 분리**: 경로만 역별. `power-paths.json`은 역별 항목(id 접미사·도면 쪽·캐비닛명). `board-info.json`·`rack-layout.json`은 기존 `station` 구조에 역 키만 추가, 장비 종류 설명은 공통 유지.
3. **경로 id**: 기본 id + `_<접미사>` 통일. SIN1은 기존 id(접미사 없음) 유지. (S6에서 `pathId(base, stn)` 함수로 예외를 감춤 — S6 인수인계서 참고)
4. **스크립트**: 템플릿/인스턴스 분리 없이 "역 인자만 추가"(C4 방식) 유지. 쪽 매핑은 역별 PDF 키워드 검색, 근거 없으면 `확인필요`. (S4/S5 인수인계서에 재검토 기준 기재)
5. **템플릿 동일성 검증(스크립트)**: SIN2=SON2 동일(150/150). SNU2 114/150, SPO2 110/150 → 쪽번호 역별 재탐색 필요.

## 인터페이스 초안
- `python make_power_paths*.py --station <접미사>` (env STN 대체, 기본 SIN1). 쪽번호·PDF·캐비닛명은 `stations.json`의 역 항목 + 스크립트별 쪽 테이블에서 읽음. 없으면 실행 중단이 아니라 해당 경로 `확인필요`.
- `python sync_related_drawings.py --base SIN1 --targets SIN2 SNU1 ...` (기본 SIN2만 = 현재 동작).
- id는 `pathId(base, stn)` 규칙: stn이 기준 역(SIN1)이면 접미사 없음.
