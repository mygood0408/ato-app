## S13 (선로전환기 팝업 개편)
- 상단 탭(정지/전환순간/전환중) + 방향 토글 + 전원 칩(제어/표시/모터). 상태 `state.wirePop {mode, dir, only, paused, view, side}`.
- `wiring_flow.py`: 흐름선을 (종류, 구간 p/m, 폴리라인, 모양)으로 반환. 표시는 `IND_LINK` 중간, 모터는 전동기 공통점, 제어는 코일 중간에서 (+)/(−) 분리. `ctrl_flows()`로 제어 R(역방향) = N 경로 반전.
- 전환순간·전환중 표시는 (+)가 N4/R3 접점에서 막히는 지점까지 + ✕. 전환순간 모터는 연하게(애니메이션 없음). 전원 하나 보기는 (+)빨강/(−)파랑, 전체 보기는 종류색.

## S14 (쌍동 표시회로 + 기계실~현장 계통 보기)
- 사실(계통도 205·206 확인): 205=우정위, 206=좌정위, 회로는 같고 정위/반위 라벨·극성만 다름(우정위 정위=R, 좌정위 정위=N). 위 단=보조, 아래 단=메인(예비단자를 쓰는, 기구함과 가까운 쪽; 205 메인=B, 206 메인=A).
- 표시회로 순서: 기구함 38(+)/37(−) → 메인 예비단자 → 보조 N4/R3 → 보조 접점·출력 → 메인 입력·접점·출력 → 기구함 40/39. 제어·모터도 기구함 → 메인 → 보조(병렬). 팝업 토글 `state.wirePop.side` 'r'/'l'. 단동은 기구함 유입선 불필요(결정).
- 코드: `wiring_flow.double_flows`·`wiring_states.LINKS`(`LANE=9`)·`sim2.py` 검증. 주의: pymupdf로 SVG를 검사하면 CSS(display:none)를 무시하므로 선 검사는 브라우저(localhost 서버 + 상태 클래스)로.
- 계통(기계실~현장) 보기: 팝업 "내부 회로 / 계통" 버튼과 진입 화면 두 곳의 "계통" 버튼. `sysSvg`·`dewemoBoardSvg`(HTML 내장 JS)가 `field-cable.json`(= HTML `FIELDCABLE`)을 그림. 유형 3가지: right(205)·left(206)·single(202). 세로형: DEWEMO-W 보드 그림 → 랙 하단 O.T. 번호(049~) → OT반·기구함(번호 없는 상자) → 단자대.
- 번호 기준 결정: **SICAS HW Design 기준.** 계통도와 다른 곳(랙 번호 짝 순서, 쌍동 제어전원 쌍)은 따르지 않고 화면 하단 메모 한 줄만. 모터·표시의 O.T. 번호는 계통도와 일치.
