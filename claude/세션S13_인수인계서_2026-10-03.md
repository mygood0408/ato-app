## 이번에 확정된 사실 (계통도·PPT 확인, 2026-10-03)
1. **표시전원 방향 = (+)가 N4·R3 로 들어오고 (−)가 단자 8·10 으로 나간다** (계통도 기구함 38(+)초록→N4, 37(−)회색→10, 앱 MP 데이터 "표시전원 N4,10"과 일치). 흐름: (+) → N4·R3 → 제어계전기 접점(C4-N4 또는 C3-R3) → 회로제어기 접점 → 출구 단자(N: 3·5, R: 4·6) → 기계실 표시 감지부(선만 표시) → 입구 단자(N: 4·6, R: 3·5) → 회로제어기 접점 → 단자 10·8 → (−). 이미 단동 `ind_n/ind_r` 흐름선에 반영됨(`wiring_flow.py`).
2. 표시 (+)/(−) 경계 = 기계실 감지부로 가는 연결선(`IND_LINK`) 중간. 빨강(+) → 파랑(−)으로 바뀜. 모터는 AC110V 라 (+)/(−) 대신 C(BX110)=빨강, D(CX110)=파랑 으로 하고 라벨은 BX/CX.
3. 제어전원 코일 극성: **정방향(단자 (+)에 + 공급) = N, 역방향 = R**. 205 정위 페이지는 단자 (+)에 −가 들어가고(=R 상태), 반위 페이지는 정방향(=N). 현재 제어 흐름선은 N(정방향) 한 방향만 있음 → R(역방향) 경로 추가 필요.
4. PPT 동작표(`선로전환기 회로도 교육자료.PPTX` 4쪽): 전환취급(전환순간) 제어계전기 새 위치·**모터 ×**·회로제어기 변화없음 / 전환중 모터 ○·회로제어기 접점 떨어짐. 앱 데이터: 모터전원 AC110V, 전환 동작 중에만 인가.
5. 연결 시뮬레이션(sim2.py, 단동 점퍼): 전환순간·전환중에는 (+)가 N4·R3 에서 막혀 출구 단자에 (+)가 나가지 않음 → **표시회로 차단**.

## 사용자 결정 (2026-10-03)
- 표시계전기(NWP/RWP) 그림은 그리지 않고 선만 이음(구현됨). 표시 (+)/(−) 경계는 위 2번(맞다고 확인).
- 점퍼·단자대 색: 구현됨(이번 세션에서 완료). 큰 단자대 보드에는 이미 점퍼 있음.
- 상단 탭: **정지 / 전환순간 / 전환중** + 방향 토글(정→반 / 반→정), 정지는 정위/반위 선택. 쌍동도 같은 구조(좌/우정위 토글은 S14).
- 전환순간·전환중 탭에서는 제어(파랑)·표시(초록)·모터(빨강)가 한 화면에 동시에 보임. 단자대의 글자 "제어 / 표시 / 모터"를 누르면 그 전원만 보이고, 이때는 (+)빨강 / (−)파랑 색.
- 전환순간의 **모터는 "아주 연하게"**(경로만, 전압 인가 전·애니메이션 없음). 전환중에도 **제어전원은 계속 보임**. 전환순간·전환중의 **표시는 차단 표시**((+)가 막히는 지점까지만 + ✕ 표시).

3. 흐름선 생성 정리: 상태 × 전원별 폴리라인을 (+)/(−) 구간으로 나눠 반환(`wiring_flow.py` 의 leg 를 (+)구간·(−)구간 두 개로 쪼갬; 표시는 `IND_LINK` 중간에서, 모터는 전동기 앞뒤, 제어는 코일 앞뒤). 전체 보기 색은 종류색(파랑·초록·빨강), 전원 하나 보기 색은 극성색.
4. 제어 R(역방향) 경로 추가(`wiring_anim.py` 의 ctrl 오버레이 방향 반대 + 단자 (+)(−) 의미 반대).
5. 전환순간·전환중 표시 차단 표시, 전환순간 모터 연한 경로.
6. 쌍동: 같은 탭 구조를 A·B 에 적용(표시 흐름은 S14 에서 계통도 기준으로 다시 만들므로 이 세션에서는 구조·모터·제어만).
7. 설명 문구(`WIRE_VIEWS` desc)·팝업 안내문 갱신. 브라우저 확인: 상태 전환, 콘솔 오류 없음, 7개 화면 스크린샷.
